# PMS-RS Workflow Documentation

This directory is the canonical working contract for agents and contributors.

Read in this order before large changes:

1. `current_state.md`
2. `architecture_principles.md`
3. `coding_rules.md`
4. `review_checklist.md`

Use `domain_expansion.md` when adding hospitality domain behavior.

Historical design notes remain under `docs/core`, `docs/architecture`, and `docs/roadmap`. Those documents are useful context, but the files in `docs/workflow` are the current implementation contract.
